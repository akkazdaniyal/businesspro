
# BusinessPro Real Estate

A responsive real estate business website developed as a portfolio demonstration project.

## Technologies
- PHP
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- MySQL (planned)

## Current Features
- Responsive navigation
- Homepage hero section
- Real estate services section
- Reusable PHP header and footer

## Local Development

```bash
php -S 127.0.0.1:8000 -t public
```

Open http://127.0.0.1:8000

Under development. Fictional demonstration business.
